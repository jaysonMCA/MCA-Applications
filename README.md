# MCA Apps

Internal MCA tools for BD and investment workflow support.

## Apps

- `DD_app/` - company due diligence app that produces MCA-style DD PDFs from researched markdown.
- `mca_strategic_review_agent/` - VC deck review / market intelligence agent and branded PDF exporter.

## Safety Notes

- Do not commit `.env` files or API keys.
- Generated reports, PDFs, local site caches, and private deck cases are intentionally ignored.
- Use each app's own `README.md` for setup and run instructions.
